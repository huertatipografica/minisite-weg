WEG — experimental display typeface by HT Fonts

ONE WAY OF EXPERIMENTATION
Carolina Giovagnoli. March 2021. Last update January 2023.

WEG* is an experimental pattern-font where legibility isn’t the focus.

This project studies how glyphs are constructed and how their ductus can be modified.
I explored how far I can move the limits if I don’t worry about legibility.
In Weg, letters are built by a single line that connects them, along with words and paragraphs. When weight decreases, the legibility of the signs increases.
It’s an ever-expanding project.

The uppercase set contains uppercase letters, lining figures and basic punctuation in three weights: Regular, Light and Thin. The lowercase is a set of typographical patterns in three weights, all connected and combinable. The current supported languages are Spanish, Guaraní and English. If you need any other language, please let me know. I would like to expand the character set.

(If you're looking for a font to use in a project where legibility is important, I suggest Telder, Cira, Kalidoscopio or any other type from our catalogue.)
